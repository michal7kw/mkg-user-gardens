<h1>Path Finder — Guide</h1>
<h2>What this page is</h2>
<p>A tool that finds how any two entities are connected — e.g. a supplement and a<br />
condition, or a gene and a biomarker — by tracing the shortest relationship path<br />
between them.</p>
<h2>Key actions</h2>
<ol>
<li><strong>Pick a start and end entity</strong> using the two search boxes.</li>
<li><strong>Run the search</strong> — Path Finder looks across the curated graph (and reference<br />
databases) for the chain linking them.</li>
<li><strong>Read the chain</strong> — each hop shows the relationship type and direction, so you<br />
can follow the mechanism end to end.</li>
<li><strong>Click any node</strong> in the path to open its detail page.</li>
</ol>
<h2>Tips &amp; gotchas</h2>
<ul>
<li>If no path is found, the two entities may live in different parts of the graph —<br />
try a broader or more canonical entity name.</li>
<li>Shorter paths are usually the more direct, better-evidenced connections.</li>
</ul>
