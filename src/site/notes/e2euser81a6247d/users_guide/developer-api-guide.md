<h1>Developer API — Guide</h1>
<h2>What this page is</h2>
<p>Manage API keys for programmatic access to your MKG data and the knowledge graph.</p>
<h2>Key actions</h2>
<ol>
<li><strong>Create an API key</strong> for an integration or script.</li>
<li><strong>Authenticate</strong> by sending the key in the <code>X-API-Key</code> header.</li>
<li><strong>Use the code examples</strong> on the page to get started quickly.</li>
<li><strong>Revoke</strong> any key you no longer use, and check usage stats.</li>
</ol>
<h2>Tips &amp; gotchas</h2>
<ul>
<li>Treat API keys like passwords — store them securely and never commit them to a<br />
repo.</li>
<li>Revoke immediately if a key may have leaked; create a fresh one to rotate.</li>
</ul>
